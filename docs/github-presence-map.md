## Status vocabulary

Each README states one of these, and the artwork carries the same label:

| Label | Meaning | Used by |
|---|---|---|
| Deployed product | Running in public at a real URL | Abdulelah.de |
| Case study / captured evaluation | Executed work with recorded evidence; not a deployed service | Raqmi |
| Prototype | Runs locally, no measured production claim | ChatUB, Stadium |
| Prototype / synthetic data | Prototype whose inputs are synthetic by design | Absher Insight |

## What is deliberately not claimed

No customers, users, uptime, revenue, adoption, awards, production deployments,
performance benchmarks or accuracy figures are claimed anywhere in this system,
except where a repository carries its own captured evidence and says exactly how
it was produced. Raqmi is the only repository with captured evaluation numbers,
and each is labelled with the run that produced it.

# Profile benchmark · 20 references

Reviewed 10 September 2026. This is a purposeful sample of respected maintainers, AI builders, founders, educators and design engineers—not a claim to rank the world's best profiles. Public following and recognizable public repositories were selection signals. No page-view estimates were used. The linked profile is the primary source for each observation; repository examples explain why the person was included.

Method: inspect current GitHub profile content, project presentation and available README source. Anthony Fu's desktop composition was also viewed in the browser. Matt Pocock's raw README confirms an image CTA with explicit light/dark picture sources. The mobile and theme columns are **design assessments**, not claims that twenty profiles were device-tested. “Not established” means the accessible evidence cannot settle the point. Absence in a text extraction is not proof that an animation does not exist.

Minimal profiles are deliberate counterexamples: an established maintainer can rely on existing reputation. Abdulelah still needs an explicit identity, a distinctive visual cue and a guided first project.

## Principles carried into this design

1. Put concrete work immediately after a short identity: antfu, Karpathy, Paco.
2. A product deserves a name and a clear outcome: shadcn, Shuding, Theo.
3. Technical authority should link to inspectable evidence: Simon Willison, Karpathy.
4. Personality can be one precise decision: Cassidy's voice, Nicky's choice of subjects.
5. One legible visual destination is enough: Matt Pocock's image CTA. Our assets are local, original SVGs, with mobile-specific artwork.
6. Meaningful interaction belongs to the subject: Nicky's explanations and Josh's interface tools. Here, it is the permission boundary of an AI action.

## Patterns rejected

Large catalogs and long update tables would delay Abdulelah's flagship. Emoji-heavy voice would imitate someone else. A stats widget proves little about system judgment and adds a remote dependency. Badge walls, typing widgets, snakes, fake terminals, visit counters and neon dashboards would obscure this specific identity. Existing-reputation minimalism alone would underspecify Abdulelah's work. No reference artwork, branding, layout code or animation was copied.

Primary implementation references: [GitHub's native details/summary support](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/organizing-information-with-collapsed-sections), [Matt Pocock's picture-source implementation](https://github.com/mattpocock/mattpocock/blob/main/readme.md).

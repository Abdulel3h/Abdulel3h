# Decision: execute without consent

**Outcome: the customer owns the order, but has not authorized this write.**

Permission to read an order does not mean permission to create a return. The model's interpretation of the conversation cannot replace an application-owned consent signal.

Keep the action pending. A safe return path needs strict arguments, ownership, valid item membership, and explicit application consent. Repeated requests should not create duplicate returns.
